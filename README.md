# # BookFlow

A microservices-based appointment management SaaS
platform for service-based businesses.

## Project Overview

BookFlow aims to simplify appointment scheduling,
employee availability management, and customer
bookings through a secure multi-tenant platform.

## Project Status

Under active development — Sprint 0.

## Planned Technology Stack

- Java 21
- Spring Boot
- Spring Cloud Gateway
- Spring Security
- Keycloak
- PostgreSQL
- RabbitMQ
- Docker
- Angular (future implementation)

## Architecture

The platform follows a microservices architecture
with independently deployable services, isolated
data ownership, and event-driven communication.

## Development Conventions

- Feature branches and pull requests
- Conventional Commits
- Automated testing
- Architecture Decision Records (ADRs)
